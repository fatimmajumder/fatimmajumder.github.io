LLM evaluation and model analysis

LLM Evaluation and Model Analysis Infrastructure

Research motivation: model evaluation should behave like a controlled measurement process, even when datasets, prompts, tokenizers, models, judges, and scoring logic evolve.

Mathematical / computational ideas
Benchmark design, deterministic lineage, slice-level regression analysis, controlled replay, and measurement under changing experimental conditions.
System or experimental contribution
Architected infrastructure for large-scale LLM evaluation with async inference scheduling, artifact caching, retry semantics, run diffs, and explicit manifests for each evaluation input.
Result or evidence
Supported 15K+ benchmark runs per week, raised exact rerun reproducibility from 74.1% to 99.96%, reduced median experiment turnaround by 84%, and surfaced a preprocessing defect that inflated internal metrics by 6.1 points.
Technologies
Python, PyTorch, Ray, FastAPI, PostgreSQL, Redis, Docker, Kubernetes, AWS.

Biomedical multimodal ML

Biomedical Multimodal ML Research

Research motivation: biomedical ML requires careful cohort construction and evaluation methodology because leakage can turn a promising model into a misleading scientific claim.

Multimodal modeling, calibration, threshold analysis, subgroup evaluation, leakage prevention, and controlled comparison across model families.

Graph learning and spatial-temporal modeling

Stochastic filtering and numerical simulation

Robust Kalman Filtering for Vehicle Localization

Research motivation: localization systems are only useful when they remain stable under noisy sensors, dropout, outliers, and covariance misspecification.

Mathematical / computational ideas
Stochastic filtering, uncertainty propagation, sensor noise modeling, robustness testing, and numerical simulation.
System or experimental contribution
Implemented a simulation framework under sensor dropout, burst noise, outliers, covariance misspecification, and asynchronous measurement streams.
Result or evidence
Reduced median localization error by 46% and 95th-percentile localization error by 41% compared with a standard Kalman filter.

Python, NumPy, SciPy, MATLAB, C++.
