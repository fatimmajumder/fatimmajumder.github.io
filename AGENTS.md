# AGENTS.md

## Site identity

This is Fatim Majumder’s personal academic/professional website. The site should present Fatim as an applied mathematics and machine learning researcher with interests in mathematical ML, scientific computing, optimization, statistical learning, reliable AI systems, LLM evaluation, biomedical ML, graph learning, quantitative research, and robust state-space estimation.

The tone should be scholarly, precise, rigorous, and readable. Prefer a research-lab style over a flashy startup portfolio style.

## Source of truth

The latest CV is the source of truth for biography, education, experience, projects, honors, skills, links, and claims.

Do not fabricate:
- publications
- conference acceptances
- advisors
- lab memberships
- grants
- awards
- metrics
- affiliations
- project outcomes

Use exact numbers from the CV when citing metrics.

## Content principles

Write for:
- graduate admissions committees
- research labs
- ML infrastructure teams
- scientific computing collaborators
- technical recruiters

Prioritize clarity over exhaustiveness. Do not copy the full CV into the website. Convert CV material into concise web sections, cards, and project summaries.

## Design principles

- Keep pages responsive and accessible.
- Use clear hierarchy and generous whitespace.
- Avoid long unbroken bullet lists.
- Prefer compact cards, expandable details, or separate project pages.
- Preserve existing visual language unless explicitly asked to redesign.
- Do not add unnecessary dependencies.

## Engineering principles

- Inspect the repository before editing.
- Maintain the existing framework and conventions.
- Prefer data-driven updates if the site already uses content/data files.
- Run build, lint, type-check, and tests when available.
- Do not remove existing links or demos unless broken.
- Summarize changed files after each task.
